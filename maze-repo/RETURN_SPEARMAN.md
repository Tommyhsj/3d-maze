## 되돌아간 수와 기하평균

되돌아간 수는 트레모가 이미 한 번 지난 간선을 반대 방향으로 다시 걸은 횟수다.
직육면체 12종 중 하나, 최근 칸 확률 q, 직진 확률 s, 루프 수 0부터 12까지를 매번 무작위로 뽑아 미로 960개를 만들었다. 트레모는 미로마다 30번의 평균이다.
기하평균은 α, β, γ를 각각 -1, 1, 2로 둔 27가지다. 되돌아간 수는 가중치를 바꾸지 않는다.
스피어만 계수는 같은 직육면체 안에서 순위를 매긴 뒤 모았다.
