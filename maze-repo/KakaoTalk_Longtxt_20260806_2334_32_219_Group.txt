목표는 연결 그래프(Connected Graph)가 주어졌을 때, 기존 논문의 흡수시간(Absorption Time) 계산 알고리즘을 그대로 이용하여

① 통로 길이 기반 흡수시간
② 차수 기반 흡수시간

을 각각 계산한 뒤,

입구(Entry)에서 출발하여 출구(Exit)까지의 최종 복잡도를 두 흡수시간의 기하평균으로 계산하는 것입니다.

==================================================
[가장 중요한 조건]
==================================================

기존 논문의 수학적 구조는 절대로 변경하지 않습니다.

즉,

- Absorbing Markov Chain
- 전이확률행렬(P)
- Transient Matrix(Θ)
- Fundamental Matrix
- 평균 흡수시간

계산 과정은 모두 기존 논문과 동일하게 유지합니다.

변경되는 것은 Weight 정의뿐이며,

서로 다른 Weight를 이용하여

기존 논문의 알고리즘을 두 번 독립적으로 수행합니다.

==================================================
[기존 논문의 계산 과정]
==================================================

각 경우마다 반드시 아래 순서를 그대로 수행합니다.

1. 연결 그래프 G=(V,E)를 생성한다.

2. 출구(exit)를 absorbing state로 설정한다.

3. 나머지 노드를 transient state로 설정한다.

4. Weight를 이용하여 전이확률행렬 P를 생성한다.

5. transient matrix Θ를 추출한다.

6. Fundamental Matrix

N = (I - Θ)^(-1)

를 계산한다.

7. 평균 흡수시간

t = N × 1

을 계산한다.

==================================================
[첫 번째 계산 : 통로 길이 기반]
==================================================

간선 길이를

L_ij

라고 한다.

Weight는

W_ij = 1 / L_ij

로 정의한다.

이 Weight를 이용하여

논문의 알고리즘을 그대로 수행한다.

입구 노드의 흡수시간을

T_length

로 저장한다.

==================================================
[두 번째 계산 : 차수 기반]
==================================================

차수는

도착 노드의 차수(degree)를 사용한다.

단,

차수 1(막다른 길)과

차수 2(직선 통로)는

분기점이 아니므로 동일한 복잡도로 취급한다.

따라서

Effective Degree

k_eff = max(2, degree)

를 사용한다.

Weight는

W_ij = 1 / k_eff

로 정의한다.

즉,

차수1 → Weight = 1/2

차수2 → Weight = 1/2

차수3 → Weight = 1/3

차수4 → Weight = 1/4

...

이 Weight를 이용하여

논문의 알고리즘을 다시 수행한다.

입구 노드의 흡수시간을

T_degree

로 저장한다.

==================================================
[최종 복잡도]
==================================================

입구 노드에서 출발하는 최종 복잡도는

Complexity = √(T_length × T_degree)

로 계산한다.

즉,

입구 노드의 두 흡수시간만 이용하여

최종 복잡도를 계산한다.

그래프 전체 평균은 계산하지 않는다.

==================================================
[입력]
==================================================

코드 상단에서 사용자가 쉽게 수정할 수 있도록

edges = [
    ("A","B",5),
    ("A","C",3),
    ("B","D",8),
    ("C","D",2),
    ...
]

형태로 입력한다.

또한

entry_node

exit_node

를 각각 입력하도록 작성한다.

Complexity = √(T_length × T_degree)

계산
