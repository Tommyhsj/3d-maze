# 3D Maze Complexity & Simulator (28기 R&E)

n×n×n 정육면체 형태 3차원 미로의 **복잡도 지표**를 직접 설계하고, 이를 검증하기 위한 **1인칭 미로 시뮬레이터**를 만드는 R&E 프로젝트입니다.

## 프로젝트 개요

- 3차원 미로를 그래프로 변환한 뒤, **흡수 마르코프 연쇄(Absorbing Markov Chain)의 도달시간(absorption time) 이론**을 이용해 복잡도를 계산합니다.
- 미로는 '칸'이 '방'이 되는 구조이며, 이동 가능한 방향은 6방향(±x, ±y, ±z)입니다.
- 계산된 복잡도가 실제 사람이 느끼는 체감 난이도와 상관관계를 갖는지 검증하기 위해, 그래프 데이터를 입력하면 시작점부터 1인칭으로 미로를 풀며 소요 시간을 측정하는 시뮬레이터를 별도로 제작 중입니다 (마인크래프트와 유사한 연속 WASD 이동).

## 복잡도 계산 방법

`complexity_geomean.py`는 Amancio et al., *Physica A* 390 (2011) 4673-4683의 흡수시간 알고리즘을 기반으로 합니다.

```
Absorbing Markov Chain → P → Θ → N = (I - Θ)^(-1) → t = N · 1
```

여기에 가중치(Weight) 정의를 두 가지로 나눠 알고리즘을 두 번 수행하고, 입구 노드의 두 흡수시간을 기하평균으로 결합합니다.

- **길이 기반**: `W_ij = 1 / L_ij` → `T_length`
- **차수 기반**: `W_ij = 1 / k_eff(j)`, `k_eff(j) = max(2, deg(j))` → `T_degree`

**최종 복잡도**: `Complexity = √(T_length × T_degree)`

`k_eff`의 하한을 2로 두는 이유는 막다른 길(차수 1)과 직선 통로(차수 2)를 복잡도 관점에서 동일하게(분기 없음) 취급하기 위함입니다.

Google Colab에서 그대로 실행 가능하도록 작성되었습니다.

## 시뮬레이터 (예정)

1인칭 미로 시뮬레이터 코드는 아직 이 저장소에 포함되어 있지 않습니다. 다음 데이터 형식을 입력으로 받도록 설계되었습니다.

```python
maze_input = {
    "dim": (n, n, n),        # 미로 크기
    "passages": [...],       # 이동 가능한 통로만 나열
    "entry": (...),          # 시작점 좌표
    "exit": (...),           # 도착점 좌표
}
```

## 향후 연구 관문

1. 흡수시간 기반 복잡도가 2차원·3차원 미로의 실제 어려움과 일치하는지 (3차원이 2차원보다 기본적으로 쉽거나 어려울 수 있다는 문제 포함)
2. 복잡도가 사람이 느끼는 체감 난이도와 비례함을 검증할 방법

## 실행 방법

```bash
pip install -r requirements.txt
python complexity_geomean.py
```

`edges`, `entry_node`, `exit_node` 값을 원하는 미로의 그래프 데이터로 바꿔서 사용하면 됩니다.
