## 흡수시간 비율과 산술·기하 비율

r = τ_length / τ_degree 이다. 산술평균과 기하평균의 비율은 이 r만으로 정해진다.

산술 / 기하 = (1 + r) / (2√r)

(산술 − 기하) / 산술 = 1 − 2√r / (1 + r)

r와 1/r은 산술/기하가 같다. r = 1이면 비율은 1이다.
아래 표의 공식 행은 미로 없이 위 식으로 계산한 값이다.
미로 행은 네 구조 규칙으로 만든 미로를 α = β = γ = 1로 계산한 값이고, 공식 곡선 위에 놓인다.
